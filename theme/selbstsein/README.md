# selbstsein.events Community Theme

Eigenständiges HumHub-Child-Theme auf Basis des HumHub-Standardthemes.

Die Gestaltung übersetzt die Bewegungsrichtung von selbstsein.events in die
Community: ruhiges Ankommen durch warme, helle Flächen; Orientierung durch
tiefes Grün; Begegnung durch Koralle; Aufmerksamkeit durch ein gut sichtbares
Gold. Alle Farben bleiben durch Text, Kontrast und Fokusmarkierungen ergänzt.

Aktivierung in einer HumHub-Installation:

```text
php protected/yii theme/switch selbstsein
```
